# Convert to Markdown

A GUI application for converting files to Markdown format.

## Dependencies

```bash
pip install markitdown tkinterdnd2
```

## Usage

1. Run the application:
   ```bash
   python gui.pyw
   ```

2. Select or drag and drop a file (PDF, Word, PowerPoint, Excel, HTML, CSV, JSON, XML, TXT, MD)

3. Click "Convert"

The converted file will be saved in the project folder with a `.md` extension.
